给 AI / 开发者的规格

本导出已抽成单一设计系统（与 Google Stitch「令牌 + 组件优先」一致）：

→ tokens.css　设计令牌唯一来源（颜色 / 圆角 / 阴影 / 字体）

→ components.css　统一组件词汇（跨 6 页复用）

→ design-spec.md　自包含实现规范（令牌 + 组件树 + 数据模型）

使用顺序：先读 tokens.css + components.css 掌握整套管件 → 再读 design-spec.md 拿每页结构 → 最后读对应 *.html 拿真实标记与内联 SVG。
